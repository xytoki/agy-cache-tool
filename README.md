# agy-cache-helper

面向 Antigravity 2.0 的上下文缓存辅助插件，用于在短暂停顿期间自动保活缓存，并在高上下文占用时趁热执行压缩，减少缓存失效带来的重复消耗。

## 功能说明

### 中段缓存保活（Ping）
- 主对话上下文处于 `20%–90%` 时，在缓存接近失效前于后台自动发送轻量保活消息，不干扰前台输入。
- 默认按模型区分间隔与单轮上限（均可在设置页调整）：
  - `Gemini*`：`Carbon` / `Neon` 间隔 `175s`，`Hydrogen` 间隔 `235s`，每轮最多 `2` 次。
  - `Claude*`：间隔 `265s`，每轮最多 `6` 次。
- 仅在短回合交互（本轮耗时 `≤ 5 分钟`）或存在运行中的后台任务时触发；刚完成手动压缩、消息撤回，或长时间未活跃的会话自动跳过。
- Subagent 常态下不保活，仅在执行后台命令且上下文 `≥ 50K` 时最多触发 `1` 次。

### 高占用热压缩
- 主对话空闲且上下文达到 `90%`（或耗时超过 `5 分钟` 的长任务结束且达到 `80%`）时，启动 `60s` 倒计时，在缓存失效前自动执行 `/compact`。
- 倒计时期间会在输入框底栏显示提示，可随时点击取消；检测到输入框存在未发送草稿时自动暂停，清空后恢复并保留至少 `15s` 缓冲。
- 后台会话进入倒计时时，会在当前窗口底栏提示并支持直接取消，无需切换标签页。
- 可在设置页关闭自动执行（改为仅记录日志），或开启演练模式进行测试。

### 侧栏面板
- **监控**：查看近期活跃会话的占用率、空闲时长与倒计时状态，支持单会话静音与手动立即保活。
- **日志**：记录每次保活的实际缓存命中率，以及热压缩的触发与取消记录。
- **设置**：自定义所有阈值、模型间隔、次数上限与开关。

## 安装与使用

```powershell
# 安装或更新插件
.\install.bat

# 卸载插件（保留配置与日志）
.\uninstall.bat

# 运行单元测试
npm test
```

首次安装后，请在 Antigravity 的 **Plugins** 面板启用 `agy-cache-helper`，并通过会话右上角 **… → Extensions → agy-cache-helper** 打开侧栏面板。

> 底栏倒计时提示需要 Antigravity 启用远程调试端口（`--remote-debugging-port=0`）；未启用时侧栏监控与后台保活功能仍正常使用。

配置文件与日志保存在 `%USERPROFILE%\.gemini\config\agy-cache-helper\`。
